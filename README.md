# KrisPekt

Рукописные конспекты по предметам: полка с тетрадями, письмо стилусом, PDF и фото, всё — прямо в браузере.

**Открыть приложение:** https://t0n1ks.github.io/KrisPekt/

© 2026 t0n1ks

> **English summary.** KrisPekt is an offline-first web app (PWA) for handwritten notes organised by subject. Write with a stylus (pressure, palm rejection, line straightening), highlight, erase, select with a lasso, add text, photos and PDF pages, and export notebooks to PDF. Everything is stored locally in the browser (IndexedDB); there is no account and no server. Interface languages: Ukrainian, Russian, German and English. Built with TypeScript and Vite, deployed to GitHub Pages by GitHub Actions. The code is proprietary: see [License](#лицензия--license).

## Что умеет

- **Полка:** предметы → тетради с обложками (24 цвета и свой цвет), порядок предметов меняется перетаскиванием за ручку или пунктами «Выше / Ниже», поиск, резервная копия и восстановление, автокопия.
- **Редактор:** ручка с нажимом стилуса и пятью типами (шариковая, перьевая, линер, карандаш, кисть), маркер, палитры на 30 и 12 цветов с недавними цветами и вводом #RRGGBB, до 5 цветов на панели, ластик по точкам или по штрихам (переключается нажатием на активный ластик, работает и кнопка-ластик стилуса), лассо (перемещение, размер, цвет, копия, удаление), текст, фото, линейка, отмена/повтор, касание двумя пальцами — отмена (выключается в ⋯), задержка стилуса — ровная линия, масштаб щипком, листание с инерцией.
- **Ладонь не листает страницу:** см. раздел «Отсечение ладони» ниже. В ⋯ редактора есть «Отмена касанием двумя пальцами» (по умолчанию включена) и «Листать только двумя пальцами» (по умолчанию выключено).
- **Замочек размера страницы:** размер тетради закреплён за первой страницей; новые страницы с замком получают его, без замка — размер предыдущей страницы.
- **PDF:** страницы PDF можно добавить как фон, тетрадь — сохранить в PDF.
- **Языки:** українська, русский, Deutsch, English.

## Как установить на телефон или планшет

1. Открой ссылку выше в Chrome (Android) или Safari (iPhone/iPad).
2. Chrome: меню **⋮ → «Добавить на главный экран»** (или «Установить приложение»). Safari: **«Поделиться» → «На экран „Домой“»**.
3. Приложение откроется в отдельном окне и будет работать без интернета.

## Где хранятся данные

- **Все тетради хранятся только в браузере на этом устройстве.** Никуда не отправляются: у приложения нет сервера, аналитики и внешних запросов.
- У каждого человека по ссылке своя полка (сначала с примером тетради). Синхронизации между устройствами нет.
- **Перенос и страховка:** на полке **⋯ → «Сохранить резервную копию»** скачивает файл `krispekt-ГГГГ-ММ-ДД.json`. На другом устройстве **⋯ → «Восстановить из копии»**. Тетради с такими же id заменятся версией из копии, остальные останутся.
- **Автокопия:** раз в 3 дня (настраивается в **⋯ → «Автокопия»**: каждый день, раз в 3 дня, раз в неделю, выключена) приложение само скачивает `krispekt-backup-ГГГГ-ММ-ДД.json`, если с прошлой копии что-то изменилось. Браузер может спросить разрешение на загрузку — ответь «Разрешить». Строка «Последняя копия: …» под заголовком полки становится жёлтой, если копии нет больше недели и есть несохранённые изменения.
- Копия проверяется целиком до записи: файл с ошибками или чужими данными не импортируется вовсе, а существующие тетради не трогаются.
- Очистка данных сайта или другой браузер покажут пустую полку — поэтому стоит иногда сохранять копию.

## Запуск локально

Нужен Node.js 22.13+ (LTS) и npm.

```bash
npm install        # зависимости
npm run dev        # сервер разработки: http://localhost:5173/KrisPekt/
npm test           # модульные тесты (Vitest)
npm run lint       # ESLint
npm run build      # сборка в dist/
npm run preview    # проверить сборку: http://localhost:4173/KrisPekt/
npm run test:e2e   # смоук-тест Playwright (после npm run build; первый раз: npx playwright install chromium)
```

Публикация: каждый push в `main` запускает GitHub Actions (`npm ci` → `npm audit` → lint → тесты → сборка → GitHub Pages).

## Архитектура

TypeScript (strict), Vite, без фреймворков: интерфейс — небольшие классы над DOM, ядро — свой рендер на canvas.

```

├─ app/             App (корень композиции, все зависимости через конструкторы), EventBus
├─ core/            типы, константы, утилиты (DOM, id, файлы, даты)
├─ i18n/            I18n и словари uk/ru/de/en
```

### Безопасность

- Строгая Content-Security-Policy (`script-src 'self'`, `style-src 'self'`, `connect-src 'self'` …) без послаблений.
- Пользовательские данные никогда не попадают в `innerHTML`; разметка из строк — только статичные SVG-иконки.
- Резервные копии, фото и PDF считаются недоверенными: строгая проверка структуры, типов по сигнатуре файла и размеров; фото перекодируются в JPEG (без EXIF/GPS); pdf.js работает без скриптов, XFA и eval.
- Данные, прочитанные из IndexedDB, тоже проверяются; повреждённые записи пропускаются.

## Отсечение ладони

Логика — в чистом классе `src/domain/TouchClassifier.ts` (покрыт тестами), `InputRouter` только выполняет его решения. Пороги — в `src/core/constants.ts`.

- **Размер касания:** касание шире или выше `PALM_SIZE_PX` (28 CSS px) — ладонь до самого отрыва; размер перепроверяется на каждом движении, палец, «расплывшийся» в ладонь, сразу перестаёт листать.
- **Сессия письма:** любое событие стилуса (касание, движение, наведение) продлевает её на `PEN_SESSION_MS` (1,5 с). Пока она идёт, один палец не листает и не рисует; масштаб и сдвиг двумя пальцами работают.
- **Отложенное листание:** один палец начинает листать, только сдвинувшись больше чем на 10 px и не раньше чем через 80 мс; если раньше пришло событие стилуса, это ладонь.
- **Откат:** если стилус коснулся экрана во время листания одним пальцем или в течение 700 мс после него, страница возвращается туда, где была, инерция останавливается.
- **Три и больше касаний** — ладонь или хват: игнорируются, пока не будут подняты все.
- Двумя пальцами отмена не срабатывает, если стилус был активен меньше 1 с назад или одно из касаний — ладонь. Линейка тоже не реагирует на ладонь.
- **Если устройство сообщает размер 1×1:** `TouchSizeProbe` берёт размер из `Touch.radiusX/radiusY` (пассивные слушатели `touchstart/touchmove` только запоминают размеры, ввод по-прежнему обрабатывают Pointer Events). `pointerdown` приходит раньше `touchstart`, поэтому такой размер известен с первого движения.

**Диагностика ввода:** в редакторе ⋯ → долгое нажатие на «Рисовать пальцем». Внизу слева появляется список последних событий указателя: тип, id, размер `ш×в` (`*` — размер из TouchEvent), нажим, кнопки, событие, как оно классифицировано (`pen` / `finger` / `palm` / `ignored` и роль касания) и `✎`, если шла сессия письма. Ничего не сохраняется и не уходит с устройства; повторное долгое нажатие выключает.
